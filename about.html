About me

I'm Ntombizakhona, and I'm learning cloud computing in public.

Cloud Languages is my 13-part series on the languages a cloud engineer uses, from English and Mathematics to Kubernetes, Terraform, and agentic IDEs. Each article explains one language and uses it to build the same project.

That project is the Languages Portfolio: an HTML, CSS, and JavaScript frontend, a Python Flask API, a MySQL database, Docker containers, Kubernetes manifests, a Java service, and Terraform for AWS.

This site is plain HTML, CSS, and JavaScript, built with Kiro and hosted free on GitHub Pages.
